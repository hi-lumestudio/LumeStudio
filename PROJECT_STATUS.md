# Lume Studio Dashboard — Project Status

## PROJECT DIRECTIVES
- **Target Market**: The Lume Studio Dashboard is built specifically for the Indonesian market. All UI text, notifications, and AI interactions must primarily use **Bahasa Indonesia**.
- **Currency**: All financial data (revenue, costs, profits) must be formatted in **Rupiah (IDR/Rp)**.

---

## SYSTEM ARCHITECTURE
The Lume Studio Dashboard is the frontend management interface for a fully autonomous WhatsApp CRM system. 
- **WhatsApp Integration (WAHA)**: The WhatsApp HTTP API (WAHA) connects to the user's WhatsApp Business account.
- **Workflow Automation (n8n)**: Every incoming WhatsApp message is intercepted by an n8n webhook. 
- **AI Brain (ChatGPT 4o Mini)**: The n8n workflow passes messages to an AI model (currently ChatGPT 4o Mini) acting as an autonomous customer service agent capable of answering FAQs and accepting new orders.
- **Database Connection (Supabase)**: The AI and n8n workflow have read/write access to Supabase. Chat histories, orders, users context, and business knowledge are continuously saved to the database.
- **Hosting**: The entire backend (WAHA + n8n) is currently hosted locally pending their first customer. Lume Studio acts as the interface to view and manage the data generated by this AI pipeline.
